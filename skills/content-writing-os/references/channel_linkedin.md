# LinkedIn Channel Guide

## Purpose

Write LinkedIn posts that feel like operator notes: direct, concrete, and decision-oriented.

## Style

- Short, scannable lines (1–2 sentences per paragraph).
- One post = one idea.
- Prefer specific examples (real workflow moments, risks, controls, practical moves).
- Use bullets only to increase scan speed (max 3–6 bullets).
- Avoid “newsletter voice” section headers in the final LinkedIn output.
- Optional: 1 visual (only if it adds clarity).

## Tone

- Calm, practical, and direct.
- No hype. No “AI will change everything”.
- Comfortable using “I” and “you” when it increases clarity.
- Opinionated only when supported by evidence or experience.

## Format Rules

- Target length: 120–220 words (hard max 280 unless explicitly requested).
- Line breaks every 1–2 sentences.
- Hook in the first 2 lines. The first line must stand alone.
- Include exactly one of:
  - a single actionable step (“One practical move this week…”), or
  - a short checklist (3–5 items), or
  - a direct question.
- CTA options (pick one):
  - Ask a question that invites a specific reply.
  - “Comment ‘X’ and I’ll send …” (only if you can fulfill the follow-up).
  - Soft invite: “If you want help applying this, DM me.”

## Safety / Credibility

- No invented facts. If a claim needs a source, keep the evidence mapping internally.
- If you include sources in the post, keep it to 1–3 links max and label as “Sources:” at the end.
- No em dashes (—). Use commas or separate sentences.

## Templates

### Template A: Operator Note (Insight → Example → Action → Question)

```text
{{hook_line}}

{{one_paragraph_explaining_the_problem_in_plain_language}}

{{one_concrete_example_or_failure_mode}}

One practical move this week:
{{single_action_step}}

{{closing_question}}
```

### Template B: Warning / Control Update (Risk → Why → Checklist → CTA)

```text
{{hook_line_warning}}

{{why_this_is_a_real_risk_for_business_owners}}

What to watch for:
- {{risk_1}}
- {{risk_2}}
- {{risk_3}}

If your team is using AI for {{high_stakes_domain}}, treat this as a governance update.

{{cta_or_question}}
```

### Template C: Event / Relationship Reflection (Observation → Lesson → Prompt)

```text
{{hook_line_context}}

{{what_you_observed}}

{{the_real_lesson_in_one_sentence}}

{{one_prompting_question_to_the_reader}}
```

## QA Checklist (before publishing)

- Is the first line strong enough to stop the scroll?
- Can someone summarize the post in one sentence?
- Did we include only one “mode” (action OR checklist OR question), not all three?
- Any sentence longer than ~30 words? Split it.
- Any vague claims (“huge impact”, “game changer”)? Replace with specific conditions.
